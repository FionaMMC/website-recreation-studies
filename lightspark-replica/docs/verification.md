## 实现与验证范围

首页在 React 入口中保留原始编译组件图，以原有响应式和交互逻辑运行；独立模式是新写的 React JSX，不声称与原站内部组件逐行一致。第三方统计代码已停用。

销售预约、产品详情、登录和文档使用原始目的地，没有在复刻中提交表单或创建金融账户。上述检查不包含外部服务的后台功能，也不等同于针对所有设备、浏览器和辅助技术的完整兼容性认证。

命令验证使用 `npm run build` 与 `npm run check`；本地组件学习页另行进行桌面和手机可视检查。没有发布线上网站。
